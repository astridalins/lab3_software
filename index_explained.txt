================================================================
  EXPLICACIÓ COMPLETA DE index.html
================================================================

index.html és l'ÚNICA pàgina real de l'aplicació. El navegador
la carrega UNA SOLA VEGADA. Tot el contingut que veus (mur,
perfil, esdeveniments...) s'injecta dinàmicament dins els seus
divs buits, sense recàrrega de pàgina.


================================================================
  BLOC 1 — HEAD: DEPENDÈNCIES EXTERNES
================================================================

<script src="jquery.min.js">

  arreu del codi. Sense això res funcionaria.

  S'executen al navegador quan l'usuari interactua amb els forms.

================================================================
  BLOC 4 — App.init (s'executa quan la pàgina carrega)
================================================================

App.init = function() {
  $.ajaxSetup({ cache: false });
    Desactiva la caché de les peticions AJAX. Força el
    navegador a demanar dades noves cada vegada.

  $('#navigation').load("Menu");
    Carrega el menú de navegació fent GET /Menu al servidor.
    El HTML resultant s'injecta dins el div#navigation.

  $('#content').load("Content");
    Carrega el contingut inicial. El servlet Content.java
    comprova si hi ha sessió i redirigeix a MainPage o
    AnonMainPage.

  App.bindEvents();
    Registra TOTS els listeners de l'aplicació. Es crida
    una sola vegada a l'inici.


================================================================
  BLOC 5 — App.bindEvents (el cor de l'aplicació)
================================================================

Aquí es defineixen TOTS els listeners de clicks i events.
S'usen sempre com $(document).on("click", ".selector", fn)
perquè els elements es carreguen dinàmicament i no existeixen
quan la pàgina arrenca.

----------------------------------------------------------------
5.1 — NAVEGACIÓ (clicks al menú)
----------------------------------------------------------------
$(document).on("click", ".menu", function(event) {
  Quan l'usuari clica qualsevol element amb classe .menu:
  1. Guarda la pàgina actual a App.currentPage
  2. Reseteja les columnes laterals
  3. Carrega la nova pàgina dins #content via AJAX
  4. Recarrega el menú i ressalta l'opció activa

----------------------------------------------------------------

----------------------------------------------------------------

----------------------------------------------------------------
5.3 — ENVIAMENT DE FORMULARIS (Login, Register)
----------------------------------------------------------------
$(document).on("submit", "form", function(event) {
  Intercepta el submit de QUALSEVOL formulari de la pàgina.
  - event.preventDefault() → evita recàrrega de pàgina
  - FormData(form) → empaqueta tots els camps automàticament
    inclosa la foto de perfil
  - $.ajax POST → envia al servlet indicat a action="..."
  - .done() → quan el servidor respon, injecta l'HTML rebut
    dins #content i recarrega el menú

----------------------------------------------------------------
5.8 — PUBLICAR POST
----------------------------------------------------------------
$(document).on("click", ".submitPost", function() {
  És el més complex. Quan l'usuari clica "Publicar":
  1. Llegeix el text del textarea (data-textarea del botó)
  2. Comprova si hi ha imatge seleccionada
  3. Si tot buit → no fa res
  4. Construeix FormData manualment amb:
     - content: text del post
     - visibility: 0 (tots) / 1 (privat) / 2 (colla)

     - collaTarget: colla destinatària si és admin

  6. POST /AddPost → si "ok", neteja el formulari i
     recarrega MainPage tornant a la pestanya activa

================================================================
  FLUX DE UNA PETICIÓ AJAX (com funciona fetch/load)
================================================================

EXEMPLE: l'usuari clica "Esdeveniments" al menú.

1. jQuery detecta el click al .menu[href=Eventos]
   → App.currentPage = "Eventos"

2. $("#content").load("Eventos")
   → El navegador fa GET http://localhost:8080/Eventos

3. Eventos.java rep la petició
   → Consulta la BD: SELECT * FROM diada
   → Afegeix les dades al request: setAttribute("diades", llista)
   → Fa forward a Eventos.jsp

4. Jetty executa Eventos.jsp
   → Substitueix ${d.name}, ${d.dia} pels valors reals
   → Executa <c:forEach> per generar les files
   → Retorna HTML pur al navegador

5. jQuery rep l'HTML
   → $("#content").html(resultat)
   → El div#content ara mostra la llista de diades

El navegador NO ha fet cap recàrrega. index.html segueix
sent la mateixa pàgina. Només ha canviat el contingut
del div#content.

DIFERÈNCIA $.post vs $.load vs $.ajax:
  $.load(url)           → GET, injecta HTML directament al div
  $.post(url, data, fn) → POST simple, rep resposta de text ("ok")
  $.ajax({...})         → Configurable, s'usa quan cal FormData
                          (fitxers) o gestió d'errors avançada
