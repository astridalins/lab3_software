  1. SEQUENCE DIAGRAMS
════════════════════════════════════════════════════════════════════════════════

  ACTORS/PARTICIPANTS QUE APAREIXEN ALS DIAGRAMES
  ─────────────────────────────────────────────────
  - Browser (client, executa jQuery/AJAX)
  - index.html (SPA shell, gestiona events globalment)
  - Servlet (Java HttpServlet @WebServlet)
  - Service (capa de lògica de negoci, Singleton)
  - Repository (accés a base de dades, Singleton)
  - SQLite DB (fitxer lab3.db)
  - HttpSession (sessió del servidor, 1 hora)


  ── SD-1: LOGIN ──────────────────────────────────────────────────────────────

  Browser → index.html       : carrega Login.jsp (GET /Login)
  Browser → Login Servlet    : POST /Login {username, password}
  Login Servlet → UserService: login(User)
  UserService → UserRepository: checkLogin(User)
  UserRepository → SQLite DB : SELECT amb JOIN users + admin WHERE username=? AND password=?
  SQLite DB → UserRepository : ResultSet (id, name, userType, isAdmin, colla, posicions, picture, ...)
  UserRepository → UserService: true / false
  UserService → Login Servlet: errors map (buit si OK)
  Login Servlet → HttpSession: session.setAttribute("user", user) [si OK]
  Login Servlet → Browser    : Welcome.jsp (si OK) o Login.jsp amb errors (si KO)

  Notes: La sessió té maxInactiveInterval de 3600s (1 hora).
         El flag isAdmin es calcula amb LEFT JOIN admin a ON a.user_id = u.id.


  ── SD-2: REGISTER ───────────────────────────────────────────────────────────

  Browser → Register Servlet : POST /Register (multipart/form-data) {name, username,
                                password, email, location, userType, posicions,
                                colla, picture (fitxer)}
  Register Servlet → UserService: saveProfilePicture(Part, username)
  UserService → FileSystem   : crea directori EXTERNAL_RESOURCES, copia fitxer
  Register Servlet → UserService: register(User)
  UserService → UserService  : validate(User) [comprova nom, username, email,
                                password (regex), posicions, colla]
  UserService → UserRepository: existsByUsername(username) [si ja existeix → error]
  UserService → UserRepository: existsByEmail(email) [si ja existeix → error]
  UserService → UserRepository: collaExists(colla) [si CASTELLER]
  UserRepository → SQLite DB : comprovacions
  UserRepository → UserService: booleans
  UserService → Login Servlet: errors map (buit si OK)
  [si errors buits]
  UserService → UserRepository: save(User)
  UserRepository → SQLite DB : INSERT INTO users (...)
  Register Servlet → Browser : Login.jsp (si OK) o Register.jsp amb errors (si KO)


  ── SD-3: PUBLICAR UN POST (AJAX) ────────────────────────────────────────────

  Browser (MainPage) → index.html  : click en .submitPost
  index.html → index.html          : llegeix data-visibility i data-textarea
  index.html → AddPost Servlet     : $.post("AddPost", {content, visibility})
  AddPost Servlet → HttpSession    : getAttribute("user")
  AddPost Servlet → PostService    : add(Post)  [Post té uid, content, visibility,
                                                 timestamp, collaName si visibility=2]
  PostService → PostRepository     : save(Post)
  PostRepository → SQLite DB       : INSERT INTO post (user_id, created_at, text,
                                      private, colla_name) VALUES (?,?,?,?,?)
                                      [created_at = SimpleDateFormat "yyyy-MM-dd HH:mm:ss"]
  SQLite DB → PostRepository       : OK
  index.html → MainPage Servlet    : $("#content").load("MainPage")
  MainPage Servlet → PostService   : getPrivatPosts, getTotsPosts, [getCollaPosts]
  PostService → PostRepository     : findPrivat(userId), findTots(userId), findColla(colla,userId)
  PostRepository → SQLite DB       : SELECT amb subqueries likeCount, likedByMe
  SQLite DB → PostRepository       : ResultSet posts
  MainPage Servlet → Browser       : MainPage.jsp renderitzat amb posts actualitzats


  ── SD-4: LIKE/UNLIKE (AJAX) ─────────────────────────────────────────────────

  Browser (MainPage) → index.html  : click en .likeToggle
  index.html → index.html          : llegeix data-liked, postId = closest("[id]")
  [si liked=0]
  index.html → LikePost Servlet    : $.post("LikePost", {id: postId})
  LikePost Servlet → PostService   : like(userId, postId)
  PostService → PostRepository     : addLike(userId, postId)
  PostRepository → SQLite DB       : INSERT OR IGNORE INTO likes (user_id, post_id)
  PostRepository → SQLite DB       : SELECT COUNT(*) FROM likes WHERE post_id=?
  PostRepository → LikePost Servlet: newCount (int)
  LikePost Servlet → Browser       : plain text "3" (nou nombre de likes)
  index.html → DOM                 : actualitza .likeCount, toggle classes w3-blue/w3-light-grey,
                                     actualitza data-liked

  [si liked=1 → $.post("UnlikePost") → DELETE FROM likes → retorna newCount]


  ── SD-5: FOLLOW/UNFOLLOW (AJAX) ─────────────────────────────────────────────

  Browser (UsersSearch) → index.html  : click en .followUser
  index.html → Follow Servlet         : $.post("Follow", {id: targetUserId})
                                        [targetUserId = $(this).closest("[id]").attr("id")]
  Follow Servlet → HttpSession        : getAttribute("user")
  Follow Servlet → UserService        : follow(followerId, targetId)
  UserService → UserRepository        : followUser(followerId, followedId)
  UserRepository → SQLite DB          : INSERT INTO follows (follower_id, followed_id)
  SQLite DB → UserRepository          : OK
  index.html → UsersSearch Servlet    : $("#content").load("UsersSearch")
  UsersSearch Servlet → UserService   : getFollowedUsers(userId, 0, 100)
  UsersSearch Servlet → UserService   : getNotFollowedUsers(userId, 0, 100)
  UserService → UserRepository        : findFollowed + findNotFollowed
  UserRepository → SQLite DB          : SELECT amb JOIN follows
  UsersSearch Servlet → Browser       : UsersSearch.jsp renderitzat (llistes actualitzades)

  [Unfollow és igual però DELETE FROM follows]


  ── SD-6: EDITAR PERFIL (AJAX) ───────────────────────────────────────────────

  Browser (Profile) → index.html    : click en .saveProfile
  index.html → UpdateProfile Servlet: $.ajax POST "UpdateProfile"
                                       data: $("#editProfileForm").serialize()
                                       [url-encoded, NO multipart]
                                       params: name, email, location, colla, posicions[]
  UpdateProfile Servlet → HttpSession: getAttribute("user") [current user]
  UpdateProfile Servlet → UserService: updateProfile(updated, current)
  UserService → UserService          : validació (nom 5-20 chars, email format,
                                        location lletres, colla vàlida, posicions vàlides)
  UserService → UserRepository       : existsByEmailExcluding(email, currentId)
                                        [comprova email únic si ha canviat]
  [si errors]
  UpdateProfile Servlet → Browser    : HTTP 400 + JSON {"nom":"error",...}
  index.html → DOM                   : mostra errors en spans #err-name, #err-email, etc.

  [si OK]
  UserService → UserRepository       : update(User)
  UserRepository → SQLite DB         : UPDATE users SET name=?,email=?,location=?,colla=?,
                                        posicions=? WHERE id=?
  UpdateProfile Servlet → HttpSession: actualitza atributs de la sessió (name, email,
                                        location, colla, posicions)
  UpdateProfile Servlet → Browser    : HTTP 200 "ok"
  index.html → Profile Servlet       : $("#content").load("Profile")
  Profile Servlet → PostService      : getPublicPostsByUser + getPrivatPostsByUser
  Profile Servlet → Browser          : Profile.jsp actualitzat


  ── SD-7: VEURE PERFIL D'ALTRE USUARI ────────────────────────────────────────

  Browser (UsersSearch) → index.html      : click en .viewProfile
  index.html → ViewUserProfile Servlet    : $.load("ViewUserProfile?uid=" + uid)
  ViewUserProfile Servlet → UserRepository: findFullById(targetId)
  UserRepository → SQLite DB              : SELECT amb LEFT JOIN admin WHERE id=?
  ViewUserProfile Servlet → UserRepository: isFollowing(viewerId, targetId)
  UserRepository → SQLite DB              : SELECT COUNT(*) FROM follows
                                             WHERE follower_id=? AND followed_id=?
  ViewUserProfile Servlet → PostService   : getPublicPostsByUser(targetId, viewerId)
  [si isFollowing=true]
  ViewUserProfile Servlet → PostService   : getPrivatPostsByUser(targetId, viewerId)
  ViewUserProfile Servlet → Browser       : UserProfile.jsp
                                            [si isFollowing=false → mostra missatge
                                             "Encara no segueixes a aquesta persona"
                                             a la pestanya Privat]


  ── SD-8: LOGOUT ─────────────────────────────────────────────────────────────

  Browser → index.html    : click menú "Logout"
  index.html → Logout Servlet: GET/POST /Logout
  Logout Servlet → HttpSession: session.invalidate()
  Logout Servlet → Browser   : redirecció a Content (pàgina inicial)

  2. USE CASE DIAGRAM
════════════════════════════════════════════════════════════════════════════════

  ACTORS
  ──────
  1. ANONYMOUS  — Usuari no autenticat (no té sessió activa)
  2. REGISTERED — Usuari registrat autenticat (CASTELLER o ESPECTADOR)
     └─ CASTELLER — Subtipus: pertany a una colla castellera
     └─ ESPECTADOR — Subtipus: espectador sense colla
  3. ADMIN      — Administrador (hereta de REGISTERED + capacitats addicionals)

  HIERARCHY:
  ANONYMOUS ──extends──▶ REGISTERED ──extends──▶ ADMIN


  USE CASES PER ACTOR
  ─────────────────────

  ANONYMOUS:
  - UC-01: Registrar-se (GET/POST /Register)
  - UC-02: Iniciar sessió (GET/POST /Login)
  - UC-03: Veure timeline global de posts públics (GET /MainPage) [pendent impl.]
  - UC-04: Veure pàgina pública d'un usuari [pendent impl.]

  REGISTERED (inclou tot d'ANONYMOUS excepte UC-01 i UC-02):
  - UC-05: Tancar sessió (GET /Logout)
  - UC-06: Veure fòrum Tots (posts visibility=0)
  - UC-07: Veure fòrum Privat (posts visibility=1, propis + seguits)
  - UC-08: Publicar post (visibility 0, 1 o 2)
  - UC-09: Eliminar post propi
  - UC-10: Fer like/unlike a un post
  - UC-11: Veure i editar el seu perfil (/Profile)
  - UC-12: Buscar i trobar usuaris (/UsersSearch)
  - UC-13: Seguir un usuari (/Follow)
  - UC-14: Deixar de seguir un usuari (/Unfollow)
  - UC-15: Veure perfil públic d'un altre usuari (/ViewUserProfile)
  - UC-16: Veure posts privats d'un usuari seguit (/ViewUserProfile + isFollowing=true)

  CASTELLER (a més de REGISTERED):
  - UC-17: Veure fòrum Colla (posts visibility=2, filtrats per colla_name)
  - UC-18: Publicar post de colla (visibility=2, colla_name s'emmagatzema al post)

  ADMIN (a més de REGISTERED):
  - UC-19: Veure gestió d'usuaris (/UsersManagement)
  - UC-20: Editar compte d'usuari aliè
  - UC-21: Eliminar compte d'usuari aliè


  RELACIONS ENTRE USE CASES
  ──────────────────────────
  UC-08 <<includes>> UC-05 [ha d'estar autenticat]
  UC-07 <<includes>> UC-13 [per veure posts privats d'altri]
  UC-16 <<extends>>  UC-15 [veure perfil + veure posts privats si seguides]
  UC-18 <<extends>>  UC-08 [publicar post és base, colla afegeix visibilitat=2]
  UC-20 <<extends>>  UC-19
  UC-21 <<extends>>  UC-19

  3. CLASS DIAGRAM + ENTITY-RELATION DIAGRAM

  ── 3A. CLASS DIAGRAM ────────────────────────────────────────────────────────

  PACKAGE: epaw.lab3.model
  ─────────────────────────

  CLASS User (implements Serializable)
  ├── int id
  ├── String name            (5-20 chars)
  ├── String username        (min 4 chars, UNIQUE)
  ├── String password        (regex: ≥8 chars, maj+min+digit+símbol)
  ├── String email           (format email, UNIQUE)
  ├── String location        (only letters)
  ├── String userType        ("CASTELLER" | "ESPECTADOR")
  ├── String posicions       (coma-separated: baixos,contraforts,enxaneta,...)
  ├── String picture         (path relatiu: assets/nom.png)
  ├── String colla           (nom colla castellera, only CASTELLER)
  └── int isAdmin            (0 o 1)

  CLASS Post (implements Serializable)
  ├── int id
  ├── int uid                (FK → users.id)
  ├── String uname           (desnormalitzat, joins users.name)
  ├── String userPicture     (desnormalitzat, joins users.picture)
  ├── Timestamp postDateTime (maps post.created_at TEXT "yyyy-MM-dd HH:mm:ss")
  ├── String content         (maps post.text, max 500)
  ├── int visibility         (0=tots, 1=privat, 2=colla)
  ├── String collaName       (maps post.colla_name, only if visibility=2)
  ├── int likeCount          (computed: COUNT(*) FROM likes WHERE post_id=id)
  └── int likedByMe          (computed: 1 si el viewer ha fet like, 0 si no)


  PACKAGE: epaw.lab3.repository
  ───────────────────────────────

  ABSTRACT CLASS BaseRepository
  └── protected Connection db  [connexió JDBC SQLite: jdbc:sqlite:lab3.db]

  CLASS UserRepository (extends BaseRepository) [Singleton]
  ├── +findAll() : List<User>
  ├── +existsByUsername(String) : boolean
  ├── +existsByEmail(String) : boolean
  ├── +existsByEmailExcluding(String, Integer) : boolean
  ├── +checkLogin(User) : boolean    [emplena User amb dades del DB si OK]
  ├── +save(User) : void
  ├── +findByName(String) : Optional<User>
  ├── +findById(Integer) : Optional<User>  [només id,name,username,picture]
  ├── +findFullById(Integer) : Optional<User>  [tots els camps + isAdmin]
  ├── +update(User) : void           [UPDATE SET name,email,location,colla,posicions]
  ├── +followUser(Integer, Integer) : void
  ├── +unfollowUser(Integer, Integer) : void
  ├── +isFollowing(Integer, Integer) : boolean
  ├── +findFollowed(Integer, Integer, Integer) : Optional<List<User>>
  ├── +findNotFollowed(Integer, Integer, Integer) : Optional<List<User>>
  └── +collaExists(String) : boolean  [whitelist de 5 colles vàlides]

  CLASS PostRepository (extends BaseRepository) [Singleton]
  ├── +VISIBILITY_TOTS   = 0
  ├── +VISIBILITY_PRIVAT = 1
  ├── +VISIBILITY_COLLA  = 2
  ├── +save(Post) : void
  ├── +delete(Integer id, Integer userId) : void  [comprova propietat]
  ├── +findPrivat(Integer userId) : List<Post>     [visibility=1, propis + seguits]
  ├── +findColla(String colla, Integer userId) : List<Post>  [visibility=2 per colla_name]
  ├── +findTots(Integer userId) : List<Post>       [visibility=0 tots]
  ├── +findPublicByUser(Integer targetId, Integer viewerId) : List<Post>  [visibility=0 per user]
  ├── +findPrivatByUser(Integer targetId, Integer viewerId) : List<Post>  [visibility=1 per user]
  ├── +findByUser(Integer, Integer, Integer) : Optional<List<Post>>  [legacy paginat]
  ├── +addLike(Integer userId, Integer postId) : int   [retorna nou count]
  ├── +removeLike(Integer userId, Integer postId) : int
  └── +getLikeCount(Integer postId) : int


  PACKAGE: epaw.lab3.service
  ───────────────────────────

  CLASS UserService [Singleton]
  ├── -UserRepository userRepository

  ├── +register(User) : Map<String,String>
  ├── +login(User) : Map<String,String>

  ├── +delete(Integer id, Integer userId) : void
  ├── +getPrivatPosts(Integer userId) : List<Post>
  ├── +getCollaPosts(String colla, Integer userId) : List<Post>
  ├── +getTotsPosts(Integer userId) : List<Post>
  ├── +getPublicPostsByUser(Integer targetId, Integer viewerId) : List<Post>
  ├── +getPrivatPostsByUser(Integer targetId, Integer viewerId) : List<Post>

  ── 3B. ENTITY-RELATION DIAGRAM ──────────────────────────────────────────────

  TABLES
  ───────

  ENTITY: users
  ├── id          INTEGER PK AUTOINCREMENT
  ├── name        VARCHAR(20) NOT NULL
  ├── username    VARCHAR(50) NOT NULL UNIQUE
  ├── password    VARCHAR(255) NOT NULL
  ├── email       VARCHAR(100) NOT NULL UNIQUE
  ├── location    VARCHAR(100)
  ├── userType    VARCHAR(100) NOT NULL  ("CASTELLER" | "ESPECTADOR")
  ├── posicions   VARCHAR(100)           (coma-separated, only CASTELLER)
  ├── picture     VARCHAR(255)           (path: assets/nom.png)
  └── colla       VARCHAR(100)           (only CASTELLER)

  ENTITY: admin
  ├── user_id     INT PK, FK → users(id) ON DELETE CASCADE
  └── is_admin    INTEGER DEFAULT 1

  ENTITY: post
  ├── id          INTEGER PK AUTOINCREMENT
  ├── user_id     INT NOT NULL, FK → users(id) ON DELETE CASCADE
  ├── parent_id   INT, FK → post(id) ON DELETE CASCADE  [per a replies, futur]
  ├── diada_id    INT                                    [per a events, futur]
  ├── private     INTEGER DEFAULT 0                      (0=tots, 1=privat, 2=colla)
  ├── colla_name  VARCHAR(100)                           (only if private=2)
  ├── text        VARCHAR(500)
  ├── image_path  VARCHAR(500)                           [per a imatges, futur]
  └── created_at  TEXT                                   ("yyyy-MM-dd HH:mm:ss")

  ENTITY: likes
  ├── user_id     INT, FK → users(id) ON DELETE CASCADE
  ├── post_id     INT, FK → post(id) ON DELETE CASCADE
  └── PRIMARY KEY (user_id, post_id)                    [evita duplicats]

  ENTITY: follows
  ├── follower_id INT, FK → users(id) ON DELETE CASCADE
  ├── followed_id INT, FK → users(id) ON DELETE CASCADE
  ├── followed_at TEXT                                   ("yyyy-MM-dd")
  └── PRIMARY KEY (follower_id, followed_id)            [evita duplicats]

  ENTITY: diada  [Events]
  ├── id          INTEGER PK AUTOINCREMENT
  ├── dia         TEXT NOT NULL
  ├── location    VARCHAR(100)
  ├── colla       VARCHAR(100)
  └── created_at  TEXT

  ENTITY: review  [Valoració de diades]
  ├── id          INTEGER PK AUTOINCREMENT
  ├── diada_id    INT NOT NULL, FK → diada(id) ON DELETE CASCADE
  ├── user_id     INT NOT NULL, FK → users(id) ON DELETE CASCADE
  ├── value       INT                                    (1-5 estrelles)
  ├── comment     VARCHAR(255)
  ├── espectador  INTEGER NOT NULL                       (0=casteller, 1=espectador)
  └── created_at  TEXT

  RELATIONSHIPS
  ──────────────
  users   1──────────────0..1  admin
            (un usuari pot ser admin)

  users   1──────────────*  post
            (un usuari publica molts posts)
            [FK: post.user_id → users.id]

  post    0..1────────────*  post
            (un post pot tenir replies; parent_id auto-referència)

  users   *──────────────*  likes
            (molts usuaris donen like a molts posts)
            [tabla pivot: likes(user_id, post_id)]

  users   *──────────────*  follows
            (molts usuaris segueixen molts usuaris)
            [tabla pivot: follows(follower_id, followed_id)]

  diada   1──────────────*  review
            (una diada té moltes valoracions)
            [FK: review.diada_id → diada.id]

  users   1──────────────*  review
            (un usuari fa moltes valoracions)
            [FK: review.user_id → users.id]

  4. MVC DIAGRAM

  ARQUITECTURA MVC AMB 4 CAPES
  ──────────────────────────────

  [BROWSER/VIEW] ←──── HTML/JSP/CSS/JS ────→ [CONTROLLER] ←→ [SERVICE] ←→ [REPOSITORY] ←→ [SQLite DB]


  DETALL DE CADA CAPA
  ────────────────────

  ── VIEW (src/main/webapp/) ──────────────────────────────────────────────────

  index.html          SPA shell: navigation bar, content div, footer,
                       jQuery event handlers globals (bindEvents)
  Login.jsp           Formulari login
  Register.jsp        Formulari registre
  Welcome.jsp         Pàgina de benvinguda post-login
  MainPage.jsp        Fòrum amb 3 tabs: Privat | Colla | Tots
  Profile.jsp         Perfil propi (view-mode + edit-mode + tabs posts)
  UserProfile.jsp     Perfil d'altre usuari (tabs Privat/Públic + lock si no segueix)
  UsersSearch.jsp     Gestió seguidors: lupa + cards amb botons Follow/Unfollow/Eye
  MenuLogged.html     Barra de navegació per a usuaris registrats
  MenuAdmin.html      Barra de navegació per a administradors (afegeix Gestió d'usuaris)
  UsersManagement.jsp Gestió admin d'usuaris
  Eventos.jsp         Pàgina d'esdeveniments (diades)
  Info.jsp            Pàgina d'informació/inici
  css/style.css       Estils globals (tema granat, cards, forms, footer)


  ── CONTROLLER (src/main/java/epaw/lab3/controller/) ────────────────────────

  Login.java          @WebServlet("/Login") @MultipartConfig
                       GET → Login.jsp | POST → login() → Welcome.jsp | Login.jsp+errors

  Register.java       @WebServlet("/Register") @MultipartConfig
                       GET → Register.jsp | POST → register() → Login.jsp | Register.jsp+errors

  Logout.java         @WebServlet("/Logout")
                       GET/POST → session.invalidate() → redirect

  Profile.java        @WebServlet("/Profile")
                       GET → carrega ownPublicPosts + ownPrivatPosts → Profile.jsp

  UpdateProfile.java  @WebServlet("/UpdateProfile")
                       POST (url-encoded) → updateProfile() → "ok" | 400+JSON errors
                       [actualitza sessió si OK]

  ViewUserProfile.java @WebServlet("/ViewUserProfile")
                       GET ?uid=X → findFullById + isFollowing + posts → UserProfile.jsp

  MainPage.java       @WebServlet("/MainPage")
                       GET → privatPosts + totsPosts [+ collaPosts si CASTELLER] → MainPage.jsp

  AddPost.java        @WebServlet("/AddPost")
                       POST {content, visibility} → add(Post) → no body (AJAX recarrega)

  DelPost.java        @WebServlet("/DelPost")
                       POST {id} → delete(id, userId) → no body

  LikePost.java       @WebServlet("/LikePost")
                       POST {id} → like(userId, postId) → plain text count

  UnlikePost.java     @WebServlet("/UnlikePost")
                       POST {id} → unlike(userId, postId) → plain text count

  Follow.java         @WebServlet("/Follow")
                       POST {id} → follow(followerId, targetId) → no body

  Unfollow.java       @WebServlet("/Unfollow")
                       POST {id} → unfollow(followerId, targetId) → no body

  UsersSearch.java    @WebServlet("/UsersSearch")
                       GET → followedUsers + notFollowedUsers → UsersSearch.jsp

  UsersManagement.java @WebServlet("/UsersManagement")
                       GET → getAllUsers() → UsersManagement.jsp

  Menu.java           @WebServlet("/Menu")
                       GET → MenuAdmin.html (si isAdmin) | MenuLogged.html

  Content.java        @WebServlet("/Content")
                       GET → pàgina inicial (Info.jsp o Login.jsp)

  Timeline.java       @WebServlet("/Timeline")  [legacy]
  Posts.java          @WebServlet("/Posts")      [legacy]
  Followed.java       @WebServlet("/Followed")   [legacy]
  NotFollowed.java    @WebServlet("/NotFollowed") [legacy]
  Info.java           @WebServlet("/Info")
  Eventos.java        @WebServlet("/Eventos")


  ── SERVICE (src/main/java/epaw/lab3/service/) ───────────────────────────────

  UserService.java    Singleton. Gestiona: register, login, updateProfile,
                       follow, unfollow, getFollowedUsers, getNotFollowedUsers,
                       getAllUsers, saveProfilePicture, validate

  PostService.java    Singleton. Gestiona: add, delete, like, unlike,
                       getPrivatPosts, getCollaPosts, getTotsPosts,
                       getPublicPostsByUser, getPrivatPostsByUser


  ── REPOSITORY (src/main/java/epaw/lab3/repository/) ────────────────────────

  BaseRepository.java Abstract. Obre connexió SQLite JDBC.
                       Connection db = DriverManager.getConnection("jdbc:sqlite:lab3.db")

  UserRepository.java Singleton. CRUD users + follows + admin check.
                       SELECT_COLS: JOIN amb admin per isAdmin flag.

  PostRepository.java Singleton. CRUD post + likes.
                       SELECT_COLS: inclou likeCount i likedByMe com a subqueries.
                       SimpleDateFormat("yyyy-MM-dd HH:mm:ss") per a TEXT columns.


  ── MODEL (src/main/java/epaw/lab3/model/) ───────────────────────────────────

  User.java           POJO. Camp isAdmin per al flag admin.
  Post.java           POJO. Camps computats: likeCount, likedByMe.


  FLUX DE DADES MVC (exemple AddPost)
  ──────────────────────────────────────

  1. VIEW (MainPage.jsp) → click .submitPost → index.html (JS event handler)
  2. index.html → $.post("AddPost", {content, visibility})
  3. CONTROLLER (AddPost.java) → rep request
  4. CONTROLLER → SERVICE (PostService.add(post))
  5. SERVICE → REPOSITORY (PostRepository.save(post))
  6. REPOSITORY → SQLite DB (INSERT INTO post)
  7. DB → REPOSITORY: OK
  8. CONTROLLER → no response body (empty 200)
  9. index.html → $.load("MainPage")
  10. CONTROLLER (MainPage.java) → SERVICE → REPOSITORY → DB → llista posts
  11. CONTROLLER → VIEW (MainPage.jsp) renderitzat amb JSTL + atributs request
